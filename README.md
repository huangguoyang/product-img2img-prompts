# 产品图生图提示词优化

把多张产品图、人物图、参考图与卖点、固定文案组织为逐图提示词，列明每张图在外部图生图工具中的上传顺序及引用范围。默认只交付可复制提示词与素材清单。

版本：1.3.1。支持用户固定文案逐字保留、产品/人物分角色引用、卖点证据表达、文字位置与大小层级、图标标注、光效和整套风格统一。

## 使用

将整个仓库下载或克隆为 `product-img2img-prompts` 目录，放入 Codex 的 Skills 目录，保留 `assets/` 与 `references/`。在任务中调用 `$product-img2img-prompts`，提供目标卖点、需要出现的文案及对应素材；人物图和风格图可按需提供。

```text
使用 $product-img2img-prompts，根据我上传的产品图、人物图和参考图，
按逐图卖点选择素材，保留全部固定文案，优化布局、字体层级、图标和标注，
输出每张图需要上传的附件顺序与完整图生图提示词。
```
