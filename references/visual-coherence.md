# 整套配色与视觉表达

学习整套商品参考时，先建立共同的视觉规则，再设计局部效果。优先分析背景、光线、产品、人物、文字、功能示意之间的关系；不是逐张挑选“好看的颜色”。本文件配合产品页面布局与特效参考库使用。

参考数码产品或本地图片资源库时，补充读取 [资源库学习方法](local-library-patterns.md)：其中区分黑蓝银色性能系列、酒红灰紫日常系列与清晰说明模块，不能把所有系列简单归为蓝色科技风。

## 当前参考体现的共同方法

这是对用户提供参考的视觉归纳，不是精确色彩采样：

- **大面积克制，少量鲜明**：米白、暖灰、浅灰和炭黑承担大面积背景；木色、米色软装与自然肤色建立生活温度；青蓝主要用于结构引导、参数强调和功能示意。不是所有图都铺满蓝色。
- **产品是稳定的视觉中心**：深色器械在浅底上形成清晰轮廓，在深底上靠边缘光和局部亮度分离。表面仍有材质与细节，不能压成黑色剪影或被特效变成发光塑料。
- **暖场景配冷色功能提示**：暖木地板、日光、柔和肤色形成真实环境，少量冷色标注帮助解释技术；二者各有用途，不把全图统一染蓝或染橙。
- **服装和陈设参与协调**：参考中的灰绿、蓝、酒红、紫等服装是不同方案里的辅助色；根据目标套图选择相容色系，不把所有参考服装颜色混进同一套。家具、植物与窗景降低竞争性，保留自然色彩而非机械去色。
- **深浅背景有分工**：浅色结构图强调清晰，暖色生活图强调使用代入，深色机械图突出内部细节。切换背景时保留字体、强调色、线条和材质质感，使其像同一套页面。
- **表达克制而具体**：大产品、明确动作、简短标题、少量大参数、贴着部件的标注构成重点。特效解释功能，不以装饰数量制造“科技感”。

不要把上述颜色固化成所有产品的唯一模板。用户指定配色、品牌规范及当前主参考优先；保留的是主次、冷暖、明暗与色彩用途之间的关系。

## 先建立整套视觉规范

内部规划或用户需要方案时，明确以下项目；只要提示词时，把必要规则落实到各条完整 Prompt，不额外输出分析表：

| 项目 | 需要确定的内容 |
|---|---|
| 基础背景 | 一组相容的浅底，以及需要技术模块时的深底；背景温度与生活场景相接 |
| 场景色彩 | 日光/室内光色温方向、木色和软装倾向、自然肤色与窗外绿色的饱和度 |
| 产品保真 | 实物颜色、Logo、材质、反光强度；任何背景都不能改变这些事实 |
| 人物与道具 | 服装和家具的辅助色、明度及饱和度，不抢过产品与关键文字 |
| 信息色 | 浅底深字、深底浅字；主标题、解释句、参数标签的明确层级 |
| 强调色 | 用于关键数值、箭头、轮廓和交互锚点的主强调色 |
| 功能补充色 | 仅在必要时用第二种颜色区分内部核心、压力或其他功能；整套含义一致 |
| 图形语法 | 引线粗细、箭头形状、卡片透明度、圆角、辉光范围与图标风格 |
| 摄影与版式 | 对比度、阴影软硬、材质真实程度、标题对齐线、边距与留白习惯 |

颜色面积以“中性底与主体占主要面积，辅助色次之，强调色少量”为判断原则，不固定机械比例。主强调色不必同时成为背景、标题、服装和所有特效的颜色。

## 模块之间怎样协调

- 极简模块承接相邻场景的灰阶或冷暖倾向。例如暖米色生活场景可接暖灰结构图；不无理由插入高饱和紫色摄影棚。
- 深色技术模块保留已有强调色与标题体系，必要时用少量暖色突出内部部件。不是每进入技术模块就更换一套字体和霓虹颜色。
- 同类箭头、尺寸线、波纹与参数徽标跨图使用相同色彩职责与线条语言；局部效果强弱可随画面复杂度调整。
- 多种场景仍应有相近的调色基调；早午晚可以改变明暗和光源，不能为了统一而失去真实时段差异。
- 关键指标不与高亮服装、饱和家具和特效同时争夺注意力。冲突时先减少装饰、背景对比或信息数量，不把所有元素都加亮。
- 系列统一不要求每张同一机位、同一背景、同一人物或同一版式。变化服务不同卖点，共同规则保证连贯。

## 提示词中的落实方式

每张 Prompt 既写本图内容，也写本图遵循的共同色彩关系。避免仅写“整体协调、高级、科技感”。

**示例表达（用于相容参考，不是默认固定配色）：**

> 延续整套暖灰与自然木色的基调，采用干净的浅暖灰背景，产品保持原有深色实物材质与柔和高光。标题用深炭灰，正文比标题低一级；青蓝仅用于尺寸箭头和关键参数，保持小面积、细线条、低强度辉光。若出现人物，服装使用低饱和的相容色，不抢过产品；接触阴影柔和清楚。保留同套页面的标题位置、字体层级和留白，避免新增不相关的饱和色或多色发光。

技术模块可将背景与文字改为深底浅字，同时保留产品、强调色、排版和图形规则。场景模块则把同样的色彩关系落实到墙面、木地板、服装和局部标注中。

## 整套检查

将所有方案作为一个系列复核：是否有无原因跳出的色温、饱和色或字体；黑色产品是否仍有细节；背景与服装是否抢主体；强调色是否仍是少量重点；浅底文字是否清晰；功能色含义是否一致；特效是否解释卖点；技术图、场景图和极简图是否能看出来自同一套设计。

未实际生图时只能确认提示词和规范的一致性，不能声称成图已经实现色彩统一。
