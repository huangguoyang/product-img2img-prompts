# 电商功能特效与信息标注

当参考图包含功能可视化、透视、发光、箭头、参数或对比信息时，按本文件设计。参考图只提供视觉表现方法；图中参数、结论、星级、品牌和文案不是目标产品的已确认资料。

## 先拆层，再选表现手法

查看参考图后区分五层：真实产品与人物、场景光影、功能特效、信息标注、文字版式。不要只提取“黑橙配色、科技感”就忽略其他层。

为每张图明确：要解释的卖点 → 最适合的表现手法 → 作用对象与位置 → 图层及遮挡 → 参数/文案来源。只选择能解释本图卖点的效果，不把效果库全部堆进一张图。没有可视化需求时可不用特效。

每个效果至少写清：
- **锚点**：哪个部件、关节、接触点或区域。
- **形态与方向**：环形波纹、渐变热区、弧形箭头、楔形色块等；从哪里到哪里。
- **颜色与强度**：提示词中给出颜色或色值、透明度、辉光范围与边缘软硬；色值不得作为画面文字出现。
- **空间关系**：位于表面、内部、后方或前方，是否贴合透视、是否被真实主体遮挡。
- **表达含义**：表现运动方向、支撑位置、空气流动还是参数差异，避免让装饰被误认成测量结果。

## 效果库与可复制表达

以下是句式组件，实际输出时替换成已确认的具体产品、位置和参数，不保留占位符。

| 手法 | 适用信息 | 必须写清的画面表达 |
|---|---|---|
| 局部透视/结构叠加 | 已知结构、作用位置 | 在指定局部叠加低透明度的内部轮廓，沿真实对象姿态对齐，其余区域保持完整实拍质感；不得凭空发明内部结构 |
| 关节/局部高亮 | 动作焦点、支撑区域 | 以关节中心为锚点设置小范围橙红发光核心，向外衰减柔和光晕；透视轮廓贴合肢体，保留皮肤和服装边界，不增加关节或骨骼 |
| 冲击波/缓冲网格 | 接触位置、缓冲概念 | 从鞋底或物体接触点向外扩散两三圈扁平椭圆波纹，叠加稀疏网格；贴合承载面的透视，中心被鞋底遮挡，接触阴影仍可见 |
| 气流/热流/水流 | 用户确认的流动功能 | 用数条流线沿实际进出方向绕过产品，源头与终点明确；穿过内部的部分仅在指定透视窗口可见，不贯穿实心外壳 |
| 动作轨迹/调整方向 | 折叠、旋转、升降 | 弧形箭头围绕真实转轴，直线箭头平行移动方向；必要时最多增加一个低透明度终态轮廓，明确它是示意，不生成第二件实体商品 |
| 局部放大窗 | 材质、连接结构、部件 | 在留白区设置圆形或圆角矩形特写窗，用细引线连接真实来源部位；特写与主产品颜色、纹理和结构一致 |
| 已知结构爆炸图 | 分层结构、装配 | 依据用户结构图或已确认部件沿同一轴线展开，保留装配对应关系；缺少内部依据时改为外部细节图 |
| 功能范围/覆盖区域 | 加热、照明、清洁覆盖 | 用半透明渐变区域限制在作用面，边缘柔化，覆盖范围须有依据；无数据时只表现局部功能概念，不画测量刻度 |

不能把颜色含义机械固定。例如红色常会被读成疼痛、过热或危险；若表现舒适和支撑，优先用更平静的青蓝/绿色或中性色，并明确语义。用户要求忠实拆解时可以描述参考图如何用红色表现压力，但不能把它自动写成产品疗效。

## 特殊标注库

- **坡度/角度**：产品下方设置沿侧视透视延伸的半透明楔形区域，下边为水平基准，上边跟随实际斜面；短虚线解释高差，上升箭头与数字靠近抬高端。坡度百分比与角度不是同一单位，`10%` 不得改写成 `10°`；整体倾斜程度须与确认参数一致，不为了突出效果夸张结构。
- **尺寸/间距**：细尺寸线、两端端点或箭头、外置数字和单位；线段沿被测边缘方向，与主体保留小间距。只标已确认数值，不猜尺寸。
- **引线标签**：先确定部件上的锚点，再写折线或直线引向哪一侧标签；尽量不交叉，不穿过 Logo、关键结构或文字，线宽和端点风格全套一致。
- **数值徽标**：数字作为第一视觉层级，单位略小且与数字相邻，说明文案位于下一行。数字不能与装饰箭头粘连到难以辨读。
- **方向与步骤**：箭头指向实际运动或操作方向；序号仅表示步骤，不冒充档位或性能数值。多个步骤按阅读方向排列。
- **状态符号**：勾/叉用于有依据的功能有无，符号配文字解释。星级只有真实、明确来源的评分才使用；不能用任意五星对两星暗示未经证实的用户评分。

## VS 对比与复合布局

对比前先确定对象：同一产品的两种模式、两种配置，或用户提供的真实对比对象。不能把无资料的对方写成性能更差。

可采用“上方使用主视觉 + 下方双对比卡”：
1. 主视觉约占上方 55%–65%，展示产品及一组主要功能特效，顶部留标题区。
2. 下方两张圆角卡使用相同的信息行和阅读顺序；若一张稍向前重叠，不能盖住另一张的参数或文字。
3. 每张卡顶部放对应部件/模式特写，中部放已确认参数，底部放对齐的功能对比行；中心可放小型 VS 徽章。
4. 重点侧可使用品牌强调色，对照侧用低饱和中性色；强调来自设计层级，不代表默认给对照侧差评。
5. 对比缺少数值依据时只呈现有资料支持的模式或结构差异；不得虚构百分比、倍率、热量消耗、关节压力、评分或健康效果。

## 每张最终 Prompt 的顺序

产品与参考图约束 → 场景与构图 → 特效及锚点 → 标注与参数 → 对比区域（如有）→ 精确上图文案 → 字体与配色 → 遮挡及错误限制。

不能只写“加入科技特效”“增加专业标注”。即使另附效果规划表，也必须把具体效果写进每张最终 Prompt，不能要求生图工具去读前表或“同上”。

JSON 交付可添加：
```json
{
  "visual_effects": [
    {
      "type": "接触波纹",
      "anchor": "前脚鞋底与跑带接触点",
      "appearance": "低强度青蓝色扁平椭圆波纹",
      "layering": "贴合跑带表面，中心被鞋底遮挡",
      "meaning": "接触区域示意，不表示实测压力"
    }
  ],
  "annotations": [],
  "comparison": null
}
```

## 参考图拆解示例：坡度跑步机

用户示例的视觉语法包含：黑色背景至暖棕地面的过渡；斜向铺开的跑步机与行走下半身；膝部半透明结构与橙红热区；鞋底青蓝网格冲击波；机身下方橙色坡度楔形区、上升箭头和百分比；底部模式特写、双对比卡、VS 徽章与勾叉信息行。

这些设计可以迁移，但示例中的“Flat Hurts. Incline Heals”、20% 压力变化、200% 热量变化和星级不因此成为目标产品事实。目标图使用这些内容需要相应资料；缺少依据时省略该结论或改用不声称疗效和量化提升的已确认卖点，固定文案有冲突时单独指出，不静默改写。

**假设用户已确认产品有 10% 坡度，并只要求表达坡度与接触位置，可写：**

> 产品保持参考图中的机身、扶手配置、跑带纹理、Logo 和比例。以三分之四侧视角展示跑步机，后方为黑至暖棕的柔和背景，下半身行走姿态自然，鞋底落在跑带上。在前脚接触点加入低强度青蓝色扁平椭圆波纹与稀疏细网格，图形贴合跑带透视，波纹中心被鞋底遮住，保留真实接触阴影；它仅为接触区域示意，不使用膝部疼痛或治疗效果图。机身侧下方加入低透明度橙色楔形坡度辅助区，底边沿水平基准，顶边跟随确认的 10% 斜面，以短虚线和紧凑向上箭头说明高差。在楔形区域靠近抬高端放置白色粗体“10%”，百分号略小，标题使用 Montserrat Bold，文字“10% Incline”。标注与产品保持间距，不遮挡 Logo，不改变产品结构，不把 10% 写成 10°；不出现未经提供的热量、压力或评分数据，画面不显示字体名称和色值代码。

此示例只演示表达完整度，不规定所有产品必须出现人物、跑步机、透视、波纹或 VS 卡。

## 成套卖点表达：真实使用 + 功能示意 + 证据细节

遇到成套商品副图参考时，不仅提取效果名称，还要判断每张图如何完成“用户利益 → 可见动作或结构 → 参数依据”的表达。参考中的图片是设计实例，不自动证明其广告结论成立。

### 套图组织方法

- 每张围绕一个用户问题安排一组相关卖点，例如“跑得开吗”“调节方便吗”“收纳占地多少”；主标题说利益，副标题解释方式，主体画面展示使用或结构，参数和底部细节补充依据。
- 一个主卖点可由多个相关功能共同支撑，例如“运动更有乐趣”关联音响、平板支架和训练程序；不能把毫不相关的参数只因有空位而塞进同一图。
- 大参数是信息焦点，单位次一级，具体含义不能省略。机身重量、承重、速度、坡度、跑带尺寸分别命名，不混成泛泛的“性能更强”。
- 主视觉选择完整使用场景、结构侧视、后方低机位、操作视角、收纳状态或面板近景。让机位服务卖点，整套不重复同一产品三分之四视角。
- 系列一致性来自场景色温、字体、边距、强调色与信息层级；允许不同图采用不同取景与信息结构，不强求每张都同一种布局。

### 第二组跑步机参考的可迁移手法

| 信息主题 | 参考中的表现方法 | 迁移时写进 Prompt 的关键 |
|---|---|---|
| 总览与主要参数 | 大产品、跑步动作、底座蓝色坡度辅助区、沿跑带透视的巨大承重数字，另附折叠小图 | 数字作为信息叠加贴合跑带平面，不生成实体印花或改变跑带；人与数字遮挡自然。辅助小图明确为同一产品另一状态，不能看成赠送第二台 |
| 电机与动力 | 机头附近的悬浮电机示意，橙色线圈与青蓝能量环，旁边大功率数字 | 指定作用部件、示意的位置、轴线与环绕方向；说明是结构解释层。无内部资料时使用抽象动力示意或已提供部件图，不能编造精确电机结构；功率不能直接证明更安静 |
| 稳固与支撑 | 两个机架侧视对齐对比，突出整机重量，底部列支撑底座、承重和框架特写 | 对比保持近似机位与尺度、共同地面基准；分别标出整机重量与最大承重。底部细节必须能对应真实部件，重量差本身不等于已验证的稳定性测试 |
| 跑步空间 | 从跑步者后方低机位沿跑带看向前方，青蓝边缘线沿跑带延伸，横纵尺寸分别标注 | 长度线沿纵深，宽度线横跨有效跑带，侧边踏板宽度单独指明；箭头贴合平面，文字保持易读。不得利用广角拉伸暗改产品比例 |
| 坡度与训练强度 | 侧面跑姿、跑台下的半透明蓝色区域、多条角度参考线和不同训练状态标签 | 区分真实支撑机构与示意层。多档坡度用同一真实转轴/支点展开，并遵循实际运动方式；不能暗示未经提供的自动程序或具体档位 |
| 操作便利 | 使用者后上方视角，手部接近扶手按键，仪表大特写，四周参数标签及按键放大图 | 手指接触实际控制位置；放大窗与左右扶手一一对应。显示内容、可控制功能以产品资料为准；围绕屏幕的文字要注明是信息标注，不生成不存在的按钮 |
| 娱乐体验 | 温暖生活场景中的跑步者，音符或细声波从音响区域延伸，底部并列音响、支架、程序图标 | 音符是轻量功能示意，锚定实际扬声器，不从任意机身位置喷出；用使用情境承载利益，底部一至三项相关功能补充，不让音效装饰遮挡人脸和屏幕 |
| 折叠收纳 | 折叠状态占据主画面，旁侧大百分比，展开/折叠尺寸小标签，底部液压机构与滚轮细节 | 展示真实折叠形态与支撑接地，百分比标清是长度、占地面积还是体积变化；有原始尺寸才能核算，不能把长度缩短说成占地或体积减少 |
| 数字训练与互联 | 控制台和平板为主体，上方排列课程、挑战、记录等界面卡，下方兼容标识 | 真实屏幕素材优先，卡片作为屏幕内容放大展示；无界面素材时可做标明性质的概念示意，但不能当作产品真实界面。第三方兼容性与品牌图标须来自产品资料 |

### 五种更精确的特效句式

这些句式描述表达方法。实际交付必须结合产品补齐真实锚点、已确认参数和文字，不能直接输出模糊占位符。

1. **附着在表面的信息**：将承重参数作为半透明信息叠加置于跑带平面，文字长轴顺着跑带纵深，并随透视缩短；鞋底自然遮住经过区域，保留跑带纹理。不把文字做成产品原有印刷。
2. **边缘引导与尺寸**：沿有效跑步区域的两条纵边绘制细青蓝导向线，前端横向尺寸线以向外的短箭头终止；标签与线条分层，避免把两个方向都写成长度。辉光仅包围线条，不把跑台变成发光透明材质。
3. **动力解释层**：在电机仓附近设置局部部件示意，以暖橙突出内部功能核心，细青蓝弧线绕轴流动，亮度由中心向外衰减；与外壳边界保持清晰关系，不让部件像未经说明地从机身穿出。
4. **多状态扇形示意**：从已确认的支点引出数条稀疏状态线，在留白处排列对应模式标签，蓝色透明区域仅填充需要解释的范围；若使用终态轮廓，只保留足以解释运动的边线，不堆叠多台实体产品。
5. **轻量音频可视化**：少量小音符与细声波从实际音响位置向人物附近舒展，逐渐变淡，保留温暖真实的场景光线；音符用于识别声音功能，不渲染成闪电、密集粒子或夸张能量爆炸。

### 文案和图形必须互相对应

- 利益标题不能仅换同义词：先确定它回答的用户问题，再选择支持它的参数、动作、部件或使用场景。画面不能讲稳固，标题却只讲高速静音。
- 一个画面中突出“机器自重”与“最大承重”时，用不同文字标签和信息位置分别解释；不能把相同的 kg 单位当作同一属性。
- 参考图的拼写和标签也需审核，不照抄疑似错误。例如 Quiet 与 Quite 不同，横向尺寸不应误标 Running Length。若用户指定逐字固定文案，提出问题并保留原文等待确认，不静默更正。
- 从展开与折叠长度计算缩短率时，用 `(展开长度 - 折叠长度) / 展开长度`；明确测量方向和舍入方式。不能把“缩短约45%”改写成“只剩45%”。
- 比较图中的竞品重量、性能、测试结论，以及 APP 功能和第三方兼容标识都须有来源。未经确认时迁移版式，不迁移这些内容。
- 输出规划时可增加“用户问题 / 主利益 / 可见依据 / 特效与标注 / 辅助细节”五项；最终独立 Prompt 必须包含实际画面表达，不能只附这张规划表。

## 补充表达：克制的动态示意与极简标注

适用于后续三图中的跑步机长页、振动平台页面及浅灰背景产品说明图。背景与页面编排见 [产品页面布局](product-page-layouts.md)。

- **参数和按钮引线**：面板近景四周排列短标签，细直线或直角折线从真实控件出发。同类功能在同一侧形成组，避免线条绕过全图；小图里的按键数量、图案与主图一致。
- **沿结构的青蓝透视区**：仅在需要解释的底座或电机仓叠加低透明度蓝色区域，外轮廓与支撑脚保留；不要把整个机身变成玻璃，也不能以辉光代替真实坡度。
- **环形运动示意**：沿已确认的转轴布置稀疏圆环与方向弧线，按透视压成椭圆，前后层次清楚；避免将它描绘成可测的磁场或虚构旋转部件。
- **缓冲接触环**：在真实缓冲支点或脚垫附近放小范围淡色波纹，贴地向外渐弱；不在任意角落生成冲击点，不让波纹被误解成产品在剧烈摇晃。
- **人物局部运动模糊**：躯干或四肢沿实际运动方向形成轻微拖影，脸部、器械、支点和参数保持可辨。不得生成额外肢体或用模糊掩盖错误姿态；同时说明这是运动表现，不是速度测量。
- **振动示意与波形卡**：平台下方可用少量垂直波纹、起伏细线表达振动，机体轮廓保持稳定。无测量数据时波形为概念示意，不画精确坐标、刻度或标为实测；振幅、频率、功率是不同参数，不能相互推导。
- **控制信号**：遥控器与接收位置之间可放轻量短弧或虚线，起终点明确；不把信号画成物理连接线，也不扩写成未提供的无线协议或连接范围。
- **虚拟场景体验**：真实器械与人物作为前景，景观或课程画面作为明确的虚拟背景/数字内容层；界面分布在不遮挡主体的两侧。避免把概念沉浸图宣称为实际投影、AR硬件或真实户外使用。

参数中特别区分“档位数”“坡度百分比”和“角度”：15档不等于15%，8档不等于8%；手动与自动调节不能混用。参考图中出现两种配置时分别绑定到对应型号，不把最强参数拼成不存在的产品。波形和场景装饰也不能充当噪声、减震或健康效果的证据。
