# 产品套图与详情页：利益、结构和使用流程

用于用户提供整套商品图、要求学习页面布局或规划副图/A+阅读顺序。与 [特效与标注参考库](effects-and-annotations.md) 配合：本文件处理信息组织和版式，后者处理效果的具体位置、形态与遮挡。

## 先判断素材是什么

区分参考拼板、单张副图、连续详情页和真实网页。拼板中的空白、重复产品、排列列数可能只是设计稿摆放，不自动成为最终页面结构。第三组健身车参考可观察到顶部白底总览和下方八个主题模块；这不意味着必须输出九张、四列网页或同样的大块顶部留白。

从参考中提取版式语法，而非机械复制内容：每张的主次信息、人物和产品的比例、标题所在留白、证据模块数量、深浅背景交替，以及套图如何逐项回答购买问题。产品类别、用户张数、图片比例与指定文案优先。

## 第三组健身车参考：八种表达模块

| 模块 | 用户问题与信息逻辑 | 布局和特效 |
|---|---|---|
| 使用情境 | 谁会使用，为什么关注舒适性 | 顶部标题和一句解释，中部完整使用场景，底部三项简短利益标签；人物互动提供使用语境。画面人物身份不自动证明专业认可或临床效果 |
| 人体支撑 | 靠背和座椅如何承托身体 | 人物侧面与靠背占主要画面，标题置于身体前方留白；沿脊柱方向叠加青蓝轮廓，靠背与座垫接触边缘局部高亮，两条短引线对应角度与座椅信息 |
| 距离与调节 | 能否调整到合适的位置 | 产品完整侧视，上方标题；座椅/靠背周围用稀疏半透明终态和双向箭头解释实际调节方向；底部一侧为调节机构特写，另一侧为编号参数列表 |
| 阻力操作 | 怎样调节，有哪些档位 | 标题下方大幅手拧旋钮近景，清楚显示手指与刻度；下方独立浅底信息卡解释档位或操作顺序。参数层级、训练进度与康复时间线是不同内容，不能互换 |
| 传动结构 | 运动如何产生，哪些结构支撑体验 | 深色技术背景与大幅局部机械透视；外壳低透明度、内部功能件暖橙高亮、轮廓冷白/青蓝，底部三列部件事实。精确内部结构必须有资料 |
| 承重与框架 | 支撑结构和承重依据是什么 | 浅底上用低对比大数字作背景信息，前景放结构示意或主体；下方一侧列结构依据，另一侧是管材截面或连接点特写。透明座垫等仅限已说明的结构解释层，不改变产品实物材质 |
| 家庭与数字体验 | 在家使用是什么体验，内容怎样参与 | 暖色生活场景、人物与完整产品占主要区域，界面卡片放在上方或侧方留白并有大小层级；标题避开复杂窗景。卡片属于数字内容示意，不是悬浮实体屏幕 |
| 全流程便利 | 上下器械、踏入踏板、握持是否方便 | 上部完整产品和单一操作动作，下部两张等宽部件特写卡；分别解释低跨入结构、踏板入口和把手功能，不把三个动作塞进一个人物姿态 |

## 人体与机械特效的空间约束

- **沿身体的支撑示意**：根据真实姿态定位脊柱/关节轮廓，线条顺着身体弯曲，透明度足以保留皮肤和衣服；高亮只集中在讲述区域。不是把整个人变成发光骨架，也不是用发光证明治疗效果。
- **接触边缘高亮**：靠背与背部、坐垫与坐姿的接触区域只加短而柔的青蓝边缘光；用标签解释“承托位置”，不要凭空生成实测压力分布。
- **调节示意**：固定车架保持清晰，只给真实可动部件一个或少量终态轮廓；平移、旋转、升降分别用对应箭头，并标清锚点。参考中的箭头方向需要结合目标产品重新核对。
- **机械透视**：外壳部分透明以露出有依据的部件，保留外轮廓与装配位置；优先“完整外形＋内部重点”，不默认全部拆成爆炸图。环绕流线仅表示已确认的运动方向，不虚构能量路径。
- **结构与承重数字**：背景数字低对比，产品优先；即使单位另列，也必须能看出数值对应的是最大承重还是其他属性。不能让产品遮挡后改变数值读法。
- **界面叠加**：主卡突出一个功能，辅助卡退后、缩小或降低对比；卡片不得遮挡操作部件和人物面部。真实截图保持文字与界面结构，概念卡明确其示意性质。

## 六种可复用版式

尺寸百分比只是初始分配建议，应根据比例、实际文案长度和手机可读性调整；不得为了凑百分比裁掉关键部件。

1. **场景主体＋底部利益栏**：标题约占顶部10%–15%，主要区域展示产品使用，底部约10%–15%排一至三项利益。人物动作与产品关系是主证据，图标为次要信息。
2. **侧面人物＋留白标注**：人物与产品沿一侧形成连续轮廓，另一侧放标题和说明；在靠背、座椅等真实锚点外置短标签，细引线不交叉。
3. **完整结构＋下方证据带**：上方约三分之二为完整产品和方向示意，下方约三分之一由机构特写与参数列表组成；两区讲同一卖点。
4. **操作特写＋解释卡**：上部大特写让人看懂手如何操作，下部浅色卡展示档位、步骤或有依据的关系；解释卡不伪装成测试图表。
5. **技术主视觉＋底部三项事实**：深色背景突出单一机械结构，下方三项信息对齐；暖色用于内部重点，冷色用于轮廓和方向，不给所有零件同等强度的辉光。
6. **上部总览＋下部双特写**：上方解释总体使用，下方两张同宽同高细节卡解释具体便利点；标题、图片和说明的位置一致，卡间保留明确间隔。

可在规划中增加 `layout_family`、`hero_subject`、`headline_zone`、`supporting_panels`、`reading_order`。最终 Prompt 必须将这些选择转成具体画面描述，不只输出字段名。

## 页面和套图的阅读节奏

建议从购买问题选择顺序：适用情境 → 舒适与适配 → 操作与调节 → 结构依据 → 日常使用与便利。该顺序是策划建议，不是声称参考已展示的完整网站流程；用户重点或固定顺序优先。

- 一张解决一个主问题，允许相关辅助信息支撑；不要每张都罗列同样的全部卖点。
- 浅色说明图负责易读与亲和，真实生活场景负责使用代入，深色技术图负责突出结构；技术图可作为视觉停顿，不必把整套都改成暗色科技风。
- 主标题、解释句、参数、局部标签分四个层级。大数字突出一个核心指标，小字紧邻说明含义；不要把所有参数都做得一样大。
- 统一标题字号层级、圆角、卡片边距、引线粗细和强调色。技术画面的深色主题可变，品牌识别与文字体系保持一致。
- 横向改竖向时重新排列内容，不直接缩小整张。多列辅助卡可变上下排列，人物与产品的关键关系必须仍然看得清；过密时拆图，不无限缩字。
- 多张独立副图不要求彼此拼接；连续A+可通过背景过渡、重复的对齐线和一致留白连接，但仍遵守具体模块尺寸。

## 极简背景与生活场景的选择

用户补充的三张参考中，图1的连续跑步机页面与图3的套图，都把纯净产品说明穿插在生活场景之间；图2则补充振动平台的使用流程、结构细节与时段场景。学习两种背景的分工，不默认每个卖点都需要家具和室内空间。

| 本图主要解释什么 | 优先背景与构图 | 可以保留的辅助内容 |
|---|---|---|
| 面板、按键、收纳槽、支架 | 白/浅灰无缝背景，大幅正面或三分之四操作台特写 | 左右放大窗、点线引导、短标签；需要解释操作时只保留必要的手 |
| 有效使用尺寸、踏板空间 | 浅灰或暖灰背景，沿产品平面的纵深机位 | 贴合透视的尺寸箭头、局部纹理块，必要时加入腿部或脚步提供使用关系 |
| 电机、传动、材料或结构 | 深灰至黑色渐变，或浅底结构特写 | 有依据的局部透视、少量环形运动示意、参数栏；无需为了“真实”补家具 |
| 调节机构、档位、状态差异 | 中性简洁背景，侧视或局部近景 | 独立状态小图、旋钮放大窗、位移箭头、准确标签 |
| 运动方式、训练模式 | 中性摄影棚或简化空间，完整产品配人物 | 人物局部运动模糊或独立的多个姿态小图；产品结构保持清晰 |
| 居家共处、观看课程、日常使用 | 真实家居场景，选择能解释体验的机位 | 轻量信息卡或界面示意；人物行为与空间关系比技术特效更重要 |
| 折叠、搬动、上下器械 | 需要解释空间动线时用房间；只解释尺寸/机构时用极简背景 | 展开/折叠状态、实际操作动作、尺寸和滚轮特写 |

极简不是没有设计：用柔和环境光、轻微地面明暗变化、接触阴影和少量轮廓光建立体积。反射可选且轻微，不生成镜面双产品。留白用于标题和参数，不能让主体过小。白底说明副图允许按任务承载文字和示意，不与白底商品主图混为一谈。

用户未指定时，先为每张确定 `background_mode`（极简产品/深色技术/真实场景/场景加说明卡），再选机位和布局。不设固定数量比例；资料以结构参数为主时，允许整套以极简为主。

### 极简图的完整提示词写法示例

> 浅暖灰无缝摄影背景，地面保留柔和接触阴影，产品操作台以三分之四近景占据中下部，保持真实面板、按键与支架结构。顶部左侧留标题区，左右各设置一个与实际按键一致的局部放大窗，细引线从对应按键引至说明，不交叉、不遮住屏幕。参数标签使用统一无衬线字体，强调色仅用于关键锚点。画面不加入家具或无关道具，产品仍具有真实材质和立体光照；上图文字仅使用用户确认文案。

## 连续长页面的模块节奏

图1可借鉴的结构是：生活场景首屏与核心参数 → 使用空间 → 动力结构 → 调节方式 → 操作便利 → 训练模式 → 折叠收纳 → 数字连接 → 其他有依据的结构或使用信息。按目标卖点取舍，不把该顺序强制用于所有产品。

- **首屏**：品牌、核心利益、完整使用画面、少量主要指标形成层次；不在首屏塞入全部参数。
- **说明模块**：一个标题、一句解释、一幅主视觉，必要时加一个局部细节或小型参数栏；标题有固定安全边距，不盖在复杂产品纹理上。
- **场景与技术切换**：暖色家居场景之后可用浅灰尺寸图，再用深色结构图强调重点；字体和强调色保持连续，避免每一块都像不同品牌。
- **状态小图**：多个坡度/模式按阅读方向排列并各自标注，同一产品保持比例与拍摄角度可比较；这些是独立状态图，不是多件商品包装清单。
- **长短版适配**：先保留核心利益与对应证据，再精简辅助文字或重排细节。参考中不同宽度的长页仅作为版式变体，不自动认定为平台官方桌面/移动尺寸。
- **模块边界**：用背景切换、共同的左右对齐线及留白组织滚动节奏；白色画布外围、拼板空区和多余副本不进入成品。

## 振动平台参考：把功能放进使用过程

图2可迁移的是“为什么需要 → 结构如何帮助 → 如何控制 → 不同方式使用 → 开始使用所需信息”的组织方法：

- 首屏用真实使用动作搭配少量半透明标签，标签靠近扶手、平台等对应部位；半透明卡需保证文字与背景对比，不成为遮挡人物的大片玻璃板。
- 把开始、调整强度、加入动作拆成三个小画面；分别讲一个操作问题，不把三步当成未经提供的训练处方。
- 高度调节、快拆销、握把材质各用一张同规格细节卡；只有真正运动的部件加入方向箭头，柔软材质以纹理与接触展示。
- 有扶手/无扶手可做并列使用状态；明确是同一产品的可选配置，拆卸方式和允许姿势须有产品依据。
- 早晨、午后、夜晚场景可表现不同使用情境，改变光线、行为和镜头，并保持产品一致；时段不是疗效承诺，不能自动继承参考中的排毒或淋巴效果文案。
- 配件总览用独立小网格、清楚数量和实际部件图；旁侧完整产品承担尺寸与重量说明，不能混入未随附的配件。

## 参考中的信息需要审核

本参考包含康复语境、按周阶段图、角度、档位、承重、噪声、耐久次数以及占位数值。学习其视觉表达，不把这些作为任意目标产品的事实：

- 康复时间线、治疗用途和医疗收益必须有相应资料支持；无依据时不按周承诺恢复，也不把“档位逐级增加”写成通用康复处方。
- 盾牌、医疗十字、脊柱透视和专业人员形象可能暗示保护、认证或专业背书；用户未提供依据时，改用中性的支撑位置、舒适姿态和真实使用说明。
- 相对比较如“更宽30%”需要比较对象；“8档阻力”和“8个座椅位置”属于不同参数，不因数字相同而共用说明。
- `XX in`、`XX mm` 等是未填数据，不能流入最终文案，也不能猜值；类似试验次数和分贝值须有资料，概念图不充当测试证据。
- 不复制明显排版粘连、重复编号和疑似错误。用户指定原文时标明疑问并等待确认，不能自行改动固定文案。

交付前逐项核对：标题说的利益是否能在图里找到对应动作或结构；每个参数有没有锚点；小特写是否来自同一产品；效果是否帮助解释；页面缩小后标题和主要指标是否仍有层级。
