# 文字在画面中的布局、大小、图标与标注

用于用户要求“学习字体布局/大小”“标题更有层级”“补图标与标注”及相似提示词优化。基于 PP 素材实际案例，先看图，再选最匹配的文字组织方式；不必每张使用所有手法。案例原图已在 [案例索引](learned-cases.json) 内。

## 先区分测量、观察和设计

- **原图像素测量**：可见字形包围盒是图片里实际有色字形的高度，不是字体的 em 字号、pt、行高或设计软件设置值。不同大小写、重音、上下延伸部会影响字形高度。不能从单张压平 JPG 反推出精确原字体或字号。
- **目视观察**：字重、对齐、空白、卡片比例与复杂背景上的文字位置可描述为近似关系；不能把目测值标成精确采样。
- **新设计建议**：为目标画幅指定的字号、比例、边距、线宽与圆角是本次设计约束，要能随文案长度和画幅调整，不称为原图原值。生图提示词中的像素要求也不是像素级排版保证。

各样本的文字区域、可见字形测量及方法见 [字号观察数据](pp-type-observations.json)，图标和标注的观察见 [图标标注数据](pp-icon-observations.json)。使用数据前确认角色和背景类型相近，不把几个不同模板的最大字号拼在同一张图。

逐图细节见 [6 例文字拆解](pp-20261021/typography-study.md) 与 [12 例图标标注拆解](pp-20261021/icons-study.md)，均可打开对应原图。4 张原图的 21 处字形区域保存了裁剪、阈值掩模和 [复核脚本](../scripts/verify_pp_type_measurements.py)。

## 字号层级不是一个固定比例

先给本图文字分角色：主标题、解释句、核心参数、单位、卡片标题、局部标签、脚注。未提供某层文案时不补字。有些图靠大小区分，有些靠字重、颜色、组距或背景容器区分，不能把所有下一级文字都强制缩小。

选择层级时：

1. **根据实际文案确定字区**。先估算它需要一行还是多行，再决定字区宽度和主体位置；不要先挤满画面才往角落塞文字。用户指定的换行保持不变。
2. **匹配相同角色**。标题与解释比较，数字与单位比较，卡标题与卡说明比较；不拿一张图的广告大字去压另一张图的功能标签。
3. **保留单位方案**。可以同字号同基线，也可以数字大、单位较小并靠基线对齐，按本次主参考选择一种。不能默认所有单位都小一半，更不能把数字与单位分到不同区域。
4. **保持组内紧、组间松**。主标题与其解释句成组；数字、单位、属性成组；标签与图标成组。关联文字之间的空白应小于不同组之间的空白。同套统一这一节奏。
5. **主次不只靠尺寸**。相近字号的参数和属性可以通过粗细或上下位置区分。把所有标题、参数、图标同时做最大，会失去焦点。
6. **缩放时重排**。横图改竖图、长英文改中文时重新分配行数和卡片位置，不把整张等比缩成密集小字。在预期显示尺寸检查关键文字，先减装饰、扩大文字区或重排，不能删改锁定文案。

具体数字应写成相对关系或针对目标分辨率的设计字号，不能同时给相互矛盾的约束。例如“标题占整图宽度的八成”和“标题无论多长都单行超大”可能无法并存。不要使用过大的字距把词拆散，参数中的小数、单位和符号保持可辨。

## 图标要作为信息的一部分

图标用来识别功能类别、组织列表或表示方向与状态，不代替真实产品细节。原图中的配件照片、接口近景、材质样本和 APP 商标分别属于实物证据或品牌资产，不应随意换成一个通用线描图标。

| 手法 | 已见案例 | 应写入提示词的关系 |
|---|---|---|
| 底部三组线描图标＋短句 | PP-B02-C01 | 三个等宽组，图标统一轮廓风格与视觉大小；图标与各自短句共用中心线，组间距离一致 |
| 圆底单功能徽章 | PP-B03-C03 | 简洁图标居中放入圆形底托，短标签紧邻；底托只为识别和对比，不扩成装饰大光球 |
| 状态卡内圆底线描符号 | PP-B03-C04 | 同一行左右图标位置一致；中性色与强调色区分状态，线条复杂程度、底托尺寸统一 |
| 勾叉或 VS 比较 | PP-B05-C05、PP-B03-C02 | 同一属性在同一行；符号与文本视觉对齐，正负语义有依据。VS 是比较关系，不是测试认证 |
| 编号圆圈＋双行文字 | PP-B02-C03 | 编号与标题组成一项，圆圈居中对齐整组或首行，全文按一套规则；信息编号不自动表示步骤顺序 |
| 音符、蓝牙或 APP 标识 | PP-B03-C09、PP-B06-C08 | 功能符号靠实际声源或设备；需要精确品牌标识时使用用户素材，不凭空生成第三方兼容标志 |

大小以关联文字和卡片为参照：行内小符号通常接近一行文字的视觉高度，独立功能图标可更大并自成一组；图标底托和图标本体分别描述。圆底图标的直径不是线描图标的字高。实际采用的线宽、实心/空心、圆角和色彩须在同一套任务中一致，避免把实物渲染图、细线图标和粗黑符号无理由混成一组。

对齐对象必须写具体：PP-B02-C01 的左置图标圆心对齐右侧两行文字的整体中心；PP-B02-C03 的编号圆圈对齐首行标题中心；PP-B05-C05 的勾叉圆心对齐该行文案中心。三者都可以正确，不笼统写“全部居中”或强行同一对齐方式。原图目测中，底部功能圈约为画宽 5%，编号圈约 4%–5%，比较勾叉圈约 3%–4%；这些是各自版面的观察，迁移时须按实际文字和卡片重新分配。

## 标注手法要写清起点、终点与意义

| 标注类型 | 适用内容与实际案例 | 落地方式 |
|---|---|---|
| 圆点＋短折线 | 焊点/梁：PP-B07-C02；控件：PP-B06-C01 | 端点落在具体部位，短折线沿留白引到标签边缘；端点小而清晰，线不穿人物和标题，不把它画成力的方向 |
| 放大窗＋来源连接 | 控制台：PP-B06-C01；机械调节：PP-B06-C10 | 窗内是同一部位的对应特写；明确来源点、窗的位置、形状、缩放关系；不换部件、不把整件产品再复制一次 |
| 尺寸双向箭头 | 跑带：PP-B07-C05、PP-B05-C08 | 定义测量边界、长度/宽度方向、端点及数值；贴面时随透视缩短，外置时与被测边平行；不混淆有效面和外尺寸 |
| 绕轴弧形箭头 | 手动坡度：PP-B06-C10；座椅旋钮：PP-B02-C03 | 圆心与真实旋钮/支点重合，方向只表达真实操作；不能拿圆箭头表示直线滑动 |
| 平移双箭头＋透明终态 | 座椅调节：PP-B02-C03 | 沿可动部件轨道，固定车架保持清晰；终态数量只为解释所需，不增加实体部件 |
| 强度条或刻度条 | 强度选择：PP-B03-C06 | 色彩、条长、标签顺序保持一致；未提供数据时是类别或相对档位示意，不画成实测数值图 |
| 毛玻璃参数卡 | PP-B05-C10 | 模糊卡背后的背景并降低干扰，保留文字对比；数值和属性对应，引线回到正确来源，卡片不挡手和传感区 |

标注线、箭头和尺寸文字属于叠加信息层，不变成产品原有印刷或物理零件。图标、编号或标签里只允许出现本次提供或授权创作的文字，不因为选了某种版式就自动新增标签。

保留参考的方法并修正其可读性问题：PP-B05-C10 的白标题局部跨亮墙，PP-B06-C01 的白细线局部经过浅背景，均不能作为任意背景都适用的正例。目标图可用净底、局部渐变或调整叠加信息颜色提高对比，功能光效不穿关键字形。

## 完整提示词需要落实的最小信息

有文字时写明：**字区位置与宽度 → 对齐 → 各角色大小关系和字重 → 换行与组距 → 背景对比**。有图标或标注时再补：**图标风格与容器 → 图文尺寸与间距 → 来源部位 → 连接路径 → 端点/箭头的含义**。

片段示例，供迁移方法而非直接当成完整交付：

> 顶部设置独立浅灰标题带，主标题与解释句共用中心轴，文字左右保留足够安全边距；采用本次确定的粗无衬线标题与较细解释字级，组内紧凑，标题带与照片之间留更大的空白。底部三个功能组等宽排列，每组一个相同视觉大小的线描图标及对应固定短句，图标与短句共用中心线。右侧部件标签以短折线连接到真实控件中心，圆点端点略强于引线，线条不穿标题、人物或其他标签。所有文字仅使用本次固定原文，具体字级与画幅相匹配。

交付前逐图检查同一角色的字体和大小是否一致、单位是否读得清、长文案是否超出字区、图标是否指向正确功能、引线是否指错部件。不能仅以“排版高级、字号合适、标注清楚”作为最终指令。
