# PP 素材：把案例方法写成图生图指令

本文件来自用户提供的 `pp素材库` 七张高清拼板，涵盖健身车、跑步机与振动平台。覆盖情况见 [学习结果](pp-20261021-summary.md)；实际案例、原图坐标、查看深度和文件校验记录见 [已学案例索引](learned-cases.json) 与 [来源清单](pp-20261021-sources.json)。这些是广告设计参考，不能据此确认产品参数或效果。原图文件名不保证品类正确，例如“椭圆机.jpg”板中可见的是带靠背的坐式健身车。

## 先匹配表达关系

用户可能说“更宽敞”“不局促”“脚有余量”，不一定说“跑带宽度”。先把日常表达映射为用户问题和可见证据，再检索索引的 `selling_points`、`visual_methods` 和案例标题。选同一视觉系列中最合适的少量案例，实际打开 `path` 对应的单模块裁剪。需要整套关系时读取 `source_path` 对应的随包原板，不依赖用户电脑上的 F 盘。

索引较长时先按关键词搜索，再只读取匹配的少量完整条目及对应案例段落；不要一次输出全部索引造成截断。可以先用 `rg` 定位词，再按 `case_id` 从 JSON 精确提取。下面的同义表达表用于扩大语义检索，不能把整份案例集当作每次必读内容。

| 用户的相似要求 | 优先检索 | 应迁移的画面关系 |
|---|---|---|
| 宽敞、步幅自然、不怕踩边、尺寸清楚 | 宽跑带、贴面尺寸、双栏对比、有效空间 | 人与使用面的真实比例；有效面边界；尺寸方向和透视 |
| 减震、缓冲、接触舒适 | 触点网格、波纹、低机位特写、缓冲 | 接触点→局部图形变化→向外衰减；鞋底/脚垫遮挡图形 |
| 静音、平稳、动力、传动 | 电机、传动路径、同轴光环、局部透壳 | 已知功能部件的位置与作用方向；有依据的结构与机制 |
| 稳固、可靠、支撑、承重 | 钢架、三角框架、焊点、连接点、测试 | 可见框架或连接结构；明确数值属于自重还是承重 |
| 占地小、好搬、能收起来 | 折叠、滚轮、收纳、状态叠化 | 真实转轴和终态；抓握及推行动作；家具空隙与机身尺度 |
| 适合不同身高、坐着舒服 | 座椅、靠背、调节、支撑、距离 | 真实接触面；可动部件与固定车架分离；操作位置 |
| 档位、爬坡、更有挑战 | 坡度、阶梯状态、旋钮、范围条 | 可见调节状态；按真实参数含义组织标签，不能混淆档位/角度/百分比 |
| 好上手、步骤简单、功能丰富 | 操作放大窗、三联步骤、主图加双卡 | 一个画面说明一个动作，按用户指定步骤组织相关卖点 |
| 智能、课程、有趣、沉浸 | APP、界面卡、场景包围、屏幕 | 屏幕内容与真实设备对应；悬浮卡属于信息层，有明确主次 |
| 运动感、振动、作用区域 | 波形、沙粒波纹、脚底光效、运动方向 | 有明确来源与方向的概念示意；主体仍清晰，不能变成测量证据 |
| 文字有设计感、多卖点清楚 | 大字叠层、浅底标题带、数字层级、卡片 | 主标题→解释句→参数/标签；文字区与画面证据一一对应 |

库中已有适用方法时，优先迁移具体关系；没有合适案例可以自行设计，但不能说它来自某张未查看的图。案例匹配不改变用户指定的素材、产品、文案、图数和主风格。

## 文字排版：观察和生成指令要分开

需要具体字级、文字占位、图标和标注时，进一步读取 [文字字级、图标与标注](pp-typography-annotations.md)；其中包含真实样本的测量口径和不同层级方案。以下比例仅为起点，不能覆盖实际案例中单位与数字同高、参数与属性同高等做法。

这批参考常用简洁无衬线字形、较粗利益标题、较细解释句、大数字与较小属性标签。无法仅凭截图确认具体字族；新任务可以按品牌规范指定字体，或明确提出一种设计用字体，而不是把它说成原图字体。

将观察落实成五个决定：

1. **标题区**：在纯净背景或低纹理墙面放标题；窗框、头部、把手和结构线不能从字中穿过。背景复杂时改用独立浅色标题带，或局部压暗/柔化背景。
2. **层级**：先给主标题一个最大字级，解释句降低字重和字号，局部标签再小一级。可将标题:副标题:标签约设为 1:0.5:0.35 作为初始设计建议，随长文案和画幅调整；这不是原图字体测量值，也不是硬规格。
3. **数值与归属**：数字可放大，单位保持可读，紧邻说明它是什么。比较时同类数值同级，不把自重、承重、峰值和持续值混在一个标签中。
4. **对齐与分组**：顶部标题居中时副标题跟同轴，局部说明卡内部统一左对齐；同套沿用同一逻辑。文字靠近对应特写或动作，细引线只连真实来源，避免相交。
5. **可读边界**：主体压住背景大字可制造层次，但不能使固定文案缺字难读；人物遮字不是所有任务的默认做法。小卡不能靠无限缩小文字容纳所有内容。

原文决定文字内容和大小写，布局只决定呈现。固定文案中的英文、数字、符号与指定换行逐字保持；相似案例的标题、口号、伪文字和占位参数都不自动加入。

## 图片布局：从拼板取模块，不取摆放画布

大图中的白色空区、排列行列和重复产品是素材组织方式，不代表需要输出相同的拼板。最终按用户图数交付独立图。根据本图卖点选布局：

- **单主视觉＋少量参数**：适合一个清晰动作或核心结构。让产品、人物和接触关系构成视觉证据，参数放在安静区。
- **主视觉＋不等宽卡片**：适合一张多卖点总览；卡片大小体现主次，结构、使用面、调节状态各有自己的证据。不要把全部文字堆在主产品上。
- **上部大图＋下部双卡**：适合主要操作搭配两个便利点，例如推行、控制、收纳；同一套色温、人物身份和卡片规格连接它们。
- **等尺度双栏或三行对比**：适合确有对比对象与依据的差异。统一机位、主体比例、姿态和比较条件，不能靠缩小竞品或改变姿态夸大差异。
- **完整外观＋局部窗口**：适合控件、材料与结构。放大窗不是另一个型号，必须和主产品的同一部位一致。
- **连续状态或步骤**：调节、折叠、开机操作分别显示状态。一个动作单元有清楚标签；透明终态属于示意，不变成多台实体商品。

按内容选极简结构图、自然生活图或深色机械图；允许一套图深浅切换，通过字级、留白、强调色和标注样式保持一致。更多版式取舍见 [页面布局](product-page-layouts.md)。

## 光效：每次写出附着关系

先写摄影光源，再写功能图形；不要让一句“科技蓝光”承担所有解释。

| 层 | 本批可见做法 | 提示词中必须落地 |
|---|---|---|
| 摄影光 | 窗边日光、柔和顶侧光、金属轮廓高光、地面弱反射 | 来源方向、软硬、保留的纹理与接触阴影；产品固有颜色保持 |
| 表面信息 | 跑带有效面着色、鞋底接触网格、坐垫接触边缘 | 哪个表面、边界、贴合透视；图形受鞋/人/零件遮挡 |
| 结构重点 | 局部机罩透明、传动路径、轴线附近光环 | 结构依据、透明范围、起止点与方向；其余区域保留实物材质 |
| 动作或范围 | 围绕转轴的弧线、线性调节箭头、低透明度终态 | 固定部件不动，可动部件有真实支点；状态数量只为解释所需 |
| 信息标注 | 端点小亮点、细折线、尺寸线、浅色或暗色卡 | 连接对象、线宽层级、标签位置；避开人脸、文字与关键部件 |

只有需要功能可视化时才叠加效果。若已用自然动作或真实尺度把卖点讲清楚，可以只保留摄影光。冷色并非固定用于所有任务；跟随用户主参考和整套强调色。概念网格、光环、波形及沙粒运动不是实测磁场、压力或振幅。

## 从案例到完整提示词

内部先完成：**目标卖点 → 产品事实 → 可见证据 → 版式 → 文字层级 → 光效附着关系 → 附件绑定**。随后将全部决定写进本张独立代码块，不只输出案例名字、索引标签或“和参考一样”。

例如用户要求“缓冲要更直观”，可以迁移成这样的画面片段：

> 低机位沿承载面拍摄鞋底触地的瞬间，产品保持参考图的真实比例与纹理。在鞋底与承载面接触点叠加稀疏青蓝细网格，沿平面透视向外渐弱，鞋底遮住其下方网格，接触阴影仍清晰。顶部预留独立低纹理标题区，主标题较粗、解释句较细，功能标签贴近对应部位。光效仅作为缓冲概念示意，不把整台机器变成透明或发光材料。

这只是方法片段。最终完整提示词仍须写入本次真实附件编号、人物身份要求、全部目标卖点、用户原文和整套规范；未有图片依据的内部结构不得添加。

## 学习时同时记录反例

本批存在错别词、宽度/长度错标、重复编号、未填数值、界面伪文字，以及未经本任务验证的测试、康复和热量声称。不能用“参考图就是这样”作为照搬理由。用户固定文案存在疑点时另行指出，原文保持；用户委托创作文案时避免沿用这些问题。返图校验应落在产品结构、人物接触、文字完整性和光效解释是否成立，不只看画面是否漂亮。
