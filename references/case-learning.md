# 从案例图片学习卖点表达

在用户提供案例并要求学习、拆解或加入本 Skill 时使用。目标是积累可用于其他产品的画面表达，不把原广告的参数、品牌、人物或产品结构带入新任务。

## 查看与拆解

先按用户分组或上传批次保留稳定编号和原文件名。多张图可先浏览联系表以筛选同系列、重复图与代表案例；要记录细节时实际打开原图。长页按原图坐标分区查看，放大检查特效锚点、引线终点和文字层级。缩略图看不清的字不猜，记录“未辨认”；只浏览联系表不得声称完成原图细节检查。

每个有效案例用以下关系拆解，按图中实际内容取舍：

| 项目 | 要记录的内容 |
|---|---|
| 来源与查看程度 | 批次、稳定编号、原文件名、原图路径；只看过联系表、打开过原图或局部放大；长页对应区域 |
| 卖点与用户问题 | 在解释什么功能或收益；分别记录看得见的线索、参考图中的广告声称和用户补充说明 |
| 可见证据 | 哪个动作、部件、状态、尺度或对比让卖点可理解；仅靠标题声称时如实记录 |
| 构图与人物 | 主体角度和占比、人物接触关系、视线、文字区、主次模块及阅读顺序 |
| 文字位置与大小 | 各文字角色的位置、字区宽度、对齐、分行、字重、相对字高；行间距与组间距、边距、数字与单位关系、文字与主体遮挡。目测与像素测量分开，字形包围盒不当作字体字号 |
| 图标与图文关系 | 线描或实心、图标本体与圆底容器、颜色及视觉大小；圆心对齐首行还是整组文字、组内/组间距；区分功能、状态、编号信息与真实操作顺序 |
| 特效与标注 | 锚定哪个部位；形态、起止方向、颜色、强度、透明度、透视、遮挡、引线与标签分别如何对应 |
| 可迁移指令 | 能用于新产品的具体画面做法，以及适用条件；不能只写“科技感”“高级感” |
| 不可直接迁移内容 | 原图品牌、具体参数、认证、竞品结论、未知内部结构及不适用于目标产品的功能 |

摄影光与信息特效分别记录：轮廓光强调体积，气流、轨迹、放大窗、尺寸线等解释特定关系。画面没有特效时可以学习其构图、动作、实物对照和留白，不额外补效果。箭头、透视等细则按 [特效与标注](effects-and-annotations.md) 使用。

把“观察到什么”和“建议怎样改进”分开，不能把建议写成原图已有内容。同系列提炼共用风格，记录每张特有的表达；重复文件可关联既有案例，不必反复写同一套结论。

字体和标注需要深入时参考 [文字字级、图标与标注](pp-typography-annotations.md)。只在可辨认、背景可分离的局部测量字形，保留原图尺寸、ROI、阈值和测量口径；复杂纹理、遮挡和发光文字可保留目测，不强求每例精确测量。明确记录参考中低对比、错误指向或语义不清的地方，迁移时修正，不能把缺陷固化成规则。

## 需要保存到 Skill 时

只为实际收到并查看的案例建立文件，使用相对于 Skill 根目录的路径：

- 新原图保存在 `assets/cases/批次编号/`，保持可查看的原始图像；裁剪图仅作补充，并能追溯原图。保留已有 `assets/references/` 和 `library-index.json` 的编号。
- 新增 `references/learned-cases.json` 时，每项记录 `case_id`、`batch_id`、`source_filename`、`path`、`sha256`、`review_depth`、`selling_points`、`visual_methods`、`series`、`notes_path`，按需增加长页区域或重复关系。`notes_path` 指向该批实际拆解文档。缺少可保存的原图时标明待补齐，不声称图库已经完整可移植。
- 批次文档保留有意义的案例卡与观察依据。跨案例重复的方法可归纳到现有专题文档，具体案例仍能通过编号定位，避免复制大量重复指南。
- 保存后核对索引中的文件与记录对应，确认图像能够打开；复制原图时校验 SHA-256。报告实际收到、已查看、已保存和未完成的数量，不把索引存在当作已经看图。

## 后续写提示词时检索

若 `references/learned-cases.json` 存在，按目标卖点、表达方法和视觉系列检索它及已有 `library-index.json`，再打开匹配原图。选择依据是解释目标卖点的效果与产品适用性，不是装饰最多。

从案例得到的方法必须落到本次目标产品的真实部位和已确认功能，写进最终可复制提示词。例如“细节放大窗”要指定放大哪个已知结构、引线接到哪里、窗口放在哪个留白区；“动作轨迹”要指定真实转轴或运动方向、前后层次及是否为示意。参考中的测量值不迁移为目标产品数据。

学习用原图默认不需要用户再上传到生图工具，迁移的方法直接写成自然语言。如果最终提示词明确要求模型参考某张案例图，则将它列入本张上传清单，提供实际可访问的文件链接并重新分配局部附件序号。

交付时说明已学习的表达方式和仍不确定的部分。未实际生成并检查返图，只能说明案例拆解及提示词映射完成，不能宣称生成效果已经验证。

用户提供返图时，对照原任务定位实际问题，如素材引用串用、人物或产品结构变化、特效遮挡、文案遗漏；优先修订受影响的提示词。需要沉淀为长期方法时保留原需求、输入对应和返图依据，不把一次工具失败归纳成所有任务的禁令。
